Instalar venv fora da pasta "taubabet", com "python -m venv venv";

Entre no venv com "venv\Scripts\activate";

Instalar bibliotecas: "pip install flask flask-sqlalchemy sqlalchemy flask-bcrypt qrcode[pil]";

Inicie com "flask --app taubabet run --debug";

(caso não dê para visualizar o banco de dados, baixe a extensão "sqlite viewer".
